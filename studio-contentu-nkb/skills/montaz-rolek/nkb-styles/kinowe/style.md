# Kinowe (styl napisów NKB)

Z katalogu stylów NKB, rodzina „Spokojne”. Klasyczne napisy jak w filmie. Całe zdanie naraz, bez podświetleń.

- Type: Poppins 400, 58 px.
- Colour: akcent = kolor marki klientki (domyślnie złoto NKB #CD9F38).
- Captions: przy dolnej krawędzi strefy bezpiecznej (position 1470), jak najdalej od twarzy.
- Pace: jak w nagraniu, pauzy przycięte.
- Graphic elements: brak.
- Sound: sam głos.

## Standing notes
- Napisy nie wchodzą na twarz: zostają przy dolnej krawędzi strefy bezpiecznej.
